# Wilting of Words - Digital Book Application

A web and mobile-optimized reading experience for "Wilting of Words" featuring:
- Interactive book reader with chapters, footnotes, and reading progress
- Ambient background music and audio player
- Rotating Diya visual animations and responsive dark aesthetic
- Firebase Authentication and Reader Access Guards
- Full offline PWA readiness

## Tech Stack
- React 19 + TypeScript + Vite
- Tailwind CSS
- Firebase Firestore & Authentication
